# Админка сайта: памятка для организаторов

Админка — это страница `/admin/` на сайте. В ней можно поменять любой текст, дату, ссылку или фото на сайте. Программист для этого не нужен.

## Как войти

1. Зарегистрируйтесь на [github.com](https://github.com/signup), если аккаунта ещё нет, и пришлите свой логин Чингизу.
2. Примите приглашение в репозиторий `youth-lab` — оно придёт на почту.
3. Откройте `https://<адрес сайта>/admin/` → **Войти через GitHub** → **Authorize**.

Если админка открылась на английском, переключите язык в настройках: аватар справа вверху → **Settings** → язык интерфейса → **Русский**. Названия кнопок ниже даны для русского интерфейса.

## Что где лежит

| Раздел админки | Что меняет на сайте |
| --- | --- |
| Основное — дата, место, цена, контакты | Дату и время, площадку, адрес, ссылку на карту, стоимость, телефон, Instagram, почту |
| Регистрация | Кнопку регистрации: статус, ссылку на Google Форму, даты, текст на странице «Регистрация» |
| Главная страница | Текст «О саммите» и цифры под первым экраном |
| Программа дня | Этапы дня: время, длительность, описание |
| Правила и оценка | Правила, критерии оценки, награды, PDF Положения |
| Итоги | Победителей и фотографии после саммита |
| Комитеты | Список комитетов: темы, источники, язык. Порядок меняется кнопкой **Изменить порядок** (перетаскиванием) |
| Жюри | Членов жюри с фото. Блок «Жюри» появится на главной, когда добавите первого |
| Партнёры | Логотипы партнёров. Блок появится на главной, когда добавите первого |

## Переводы

Слева в редакторе — русский текст, справа — казахский или английский (переключаются кнопками над полями). Сначала заполняйте русский. Если перевод поля пустой, на казахской и английской версиях сайта покажется русский текст — так что ничего не сломается, даже если перевод ещё не готов.

## Как сохранить

Нажмите **Сохранить** (или Ctrl+S). Сайт обновится сам через 1–2 минуты. Если через 5 минут изменений нет, напишите Чингизу: скорее всего, в правке ошибка, а на сайте пока осталась прошлая версия.

## Частые задачи

**Открыть регистрацию.** Раздел «Регистрация»: вставьте ссылку на Google Форму, выберите статус «Открыта», при желании укажите последний день регистрации. Без ссылки на форму кнопка не появится — сайт будет показывать «Регистрация скоро откроется».

**Объявить дату открытия регистрации.** Там же: статус «Скоро откроется» и поле «Дата открытия регистрации». На сайте будет «Регистрация откроется 16 ноября 2026 г.».

**Указать время саммита.** Раздел «Основное»: поля «Начало» и «Окончание». Пока они пустые, на сайте написано «Время уточняется». Время этапов — в разделе «Программа дня».

**Добавить члена жюри.** Раздел «Жюри» → **Создать** → имя, должность, фото → **Сохранить**. Фото лучше квадратное. Можно загружать прямо с телефона: админка сама уменьшит и сожмёт картинку.

**Опубликовать итоги.** Раздел «Итоги»: добавьте победителей (комитет, награда, команда, школа) и фотографии, затем включите «Показать итоги на сайте». В меню появится раздел «Итоги».

**Загрузить Положение.** Раздел «Правила и оценка» → поле «Положение (PDF)». На странице правил появится кнопка «Скачать Положение».
