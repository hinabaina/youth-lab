# Youth Research Summit — сайт

Сайт межшкольного исследовательского турнира Youth Research Summit (организатор — Youth Lab) с админкой, в которой организаторы сами меняют тексты, даты, комитеты, жюри и итоги без программиста.

- Сайт: три языка — русский (основной, в корне сайта), казахский (`/kk/`) и английский (`/en/`).
- Админка: `/admin/` — вход через GitHub, правки сохраняются в этот репозиторий, сайт обновляется сам за 1–2 минуты.
- Хостинг: Cloudflare Pages (бесплатный тариф разрешает коммерческое использование, а участие в саммите платное).

Инструкции:

- [docs/DEPLOY.md](docs/DEPLOY.md) — первый запуск на Cloudflare и вход в админку (один раз, для разработчика).
- [docs/ADMIN.md](docs/ADMIN.md) — памятка для организаторов: как пользоваться админкой.

## Стек

| Что | Чем | Зачем |
| --- | --- | --- |
| Сайт | [Astro](https://astro.build) 7, статическая сборка | Готовые HTML-страницы: быстро открываются с телефона, нечему ломаться на сервере |
| Стили | Tailwind CSS 4, шрифты Montserrat и Inter (с казахскими буквами) | |
| Админка | [Sveltia CMS](https://sveltiacms.app) | Тексты хранятся в репозитории, история правок — в git, отдельная база не нужна |
| Вход в админку | Функции Cloudflare Pages (`functions/api`) | Вход через GitHub на этом же сайте, без сторонних сервисов |
| Хостинг | Cloudflare Pages | Бесплатно, сайт пересобирается после каждой правки |

## Как устроен проект

```
public/admin/config.yml     разделы и поля админки
src/content/                содержимое сайта (его правит админка)
  site/event.yml            основное: дата, место, цена, контакты
  site/registration.yml     регистрация: статус, ссылка на форму, даты
  site/home.yml             главная: подводка, формат дня, цифры, шаги участия, «Что вы получите», вопросы и ответы
  site/program.yml          программа дня
  site/rules.yml            правила, критерии оценки, награды, PDF Положения
  site/results.yml          итоги (включаются после саммита)
  committees/*.yml          комитеты
  jury/*.yml                жюри
  partners/*.yml            партнёры
public/uploads/             фото и файлы, загруженные через админку
src/lib/schemas.ts          проверка содержимого при сборке
src/lib/localize.ts         подстановка русского текста, если перевода нет
src/i18n/ui.ts              подписи интерфейса (меню, кнопки) на трёх языках
src/pages/[...locale]/      страницы: главная, комитеты, правила, регистрация, итоги
src/components/home/        блоки главной: первый экран, формат, выбор комитета, оценка, награды, финальный призыв
src/components/             общие блоки: шапка, подвал, шаги участия, программа, вопросы, плашка регистрации на телефоне
src/scripts/                появление блоков при прокрутке, счётчики, вкладки
src/icons/                  иконки Lucide (только нужные), список для поля «Иконка» в админке
src/pages/admin/index.astro страница админки
functions/api/              вход в админку через GitHub
scripts/copy-cms.mjs        кладёт файлы Sveltia CMS в public/admin перед сборкой
scripts/share-images.mjs    рисует картинки превью ссылки public/brand/share-{ru,kk,en}.jpg
```

Каждый файл в `src/content` хранит все три языка: блоки `ru`, `kk` и `en`. Русский обязателен. Если поле на казахском или английском пустое, на сайте показывается русский текст, поэтому переводить можно постепенно.

При сборке содержимое проверяется схемами из `src/lib/schemas.ts`. Если в файле ошибка, Cloudflare не опубликует новую версию, и на сайте останется предыдущая рабочая.

## Локальный запуск

Нужен Node.js 22.23.4 или новее (версия указана в `.nvmrc`).

```sh
npm install
npm run dev      # сайт на http://localhost:4321, админка на http://localhost:4321/admin/
npm run build    # сборка в dist/
npm run check    # проверка типов и шаблонов
```

Локально админку удобно открывать в Chrome или Edge кнопкой «Work with Local Repository» (выберите папку репозитория): правки сохраняются прямо в файлы на диске, GitHub для этого не нужен.

## Как добавить новое поле

1. Добавьте поле в нужный раздел `public/admin/config.yml`.
2. Добавьте его в схему в `src/lib/schemas.ts`. Имя должно совпадать.
3. Выведите поле на странице в `src/pages/[...locale]/`.

Подписи кнопок и меню (не содержание) лежат в `src/i18n/ui.ts` и меняются в коде.

## Превью ссылки в мессенджерах

Когда ссылку на сайт отправляют в WhatsApp, Telegram или Instagram, показывается картинка `public/brand/share-<язык>.jpg` (1200×630), название и подпись «дата, город. подзаголовок». Подпись сайт собирает из админки сам. Картинку рисует `scripts/share-images.mjs` по названию, городу и подзаголовку из раздела «Основное» в админке; если они поменялись, перерисуйте её (команда — в начале скрипта) или замените файлы своими картинками того же размера.

## Как добавить иконку

1. Возьмите SVG нужной иконки с [lucide.dev](https://lucide.dev) и добавьте её содержимое (без тега `<svg>`) в `src/icons/icons.ts`.
2. Чтобы иконку можно было выбрать в админке, добавьте её в список `&icon_options` в `public/admin/config.yml`.

Все анимации отключаются, если в системе включено «Уменьшение движения», а без JavaScript страница показывается полностью, просто без анимаций.
